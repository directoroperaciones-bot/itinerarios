# Itinerarios de Caminos

Sitio público (GitHub Pages) con los itinerarios interactivos de los grupos de Caminos — Agencia de viajes.

- Cada itinerario es un archivo `CODIGO-xxxxxx.html` que publica la app de documentos con el botón «Publicar para el grupo».
- `sw.js` guarda en el celular cada itinerario abierto para poder verlo sin internet.
- Dirección: https://directoroperaciones-bot.github.io/itinerarios/
